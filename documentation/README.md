# Project Overview

### Business Goal
- To make *Villa Prescilla Booking Contracts* **easier to create, store, access, and modify**.

### **Software Engineering Goal**
- To design and implement a **centralized contract management system** with a structured database schema, intuitive UI components for dynamic document generation, and a secure API for real-time CRUD operations.

### Technical Objectives
| Business Need    | Engineering Objective                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| Easier to Create | Develop **reusable templates** and a logic-driven form builder that auto-populates data into PDF. |
| Easier to Store  | Implement a **relational database**.                                                              |
| Easier to Access | Build a **search and indexing engine**.                                                           |
| Easier to Modify | Create a **version control system**.                                                              |

### Technical Architecture Overview
- **Frontend:** A responsive web interface for data entry.
- **Backend:**  The Centralized Relational Database for data accessibility.
